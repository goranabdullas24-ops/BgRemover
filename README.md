# لابردنی باکگراوند — وەشانی ٢

## چی نوێیە
- **گەڕان بە ناو**: ناوێک بنووسە (بۆ نموونە «گوڵی نێرگز») → وێنەکان دەردەکەون → یەکێک دابگرە. لینکیش هێشتا کار دەکات.
- **لابردنی وردتر**: ML Kit Subject Segmentation + Guided Filter بۆ لێوار و قژ + لابردنی هالۆی سپی + لابردنی پەڵەی هەڵە.
- دوای هەڵبژاردنی وێنە، باکگراوند **خۆکارانە** لادەبرێت.
- ڕەنگی باکگراوند (ڕوون، سپی، ڕەش، شین، سوور، سەوز) — باشە بۆ وێنەی پاسپۆرت.
- پاشەکەوت لە گاڵەری (PNG) و ناردن.

## کردنەوە
1. فۆڵدەری `BgRemover` لە **Android Studio** بکەرەوە (File › Open).
2. ئەگەر داوای Gradle Wrapper کرد، «OK» دابگرە.
3. ▶ Run. (کەمترین ئەندرۆید: 10)

## کلیلەکان (ئارەزوومەندانە، لە ⚙ ی ناو ئەپ)
| بۆ | لە کوێ | تێبینی |
|---|---|---|
| ئەنجامی ڕاستەوخۆی **Google Images** | serper.dev | بەخۆڕایی بۆ دەستپێکردن. بەبێ کلیل لە Wikimedia دەگەڕێت |
| وردترین لابردن (قژ) | remove.bg/api | چەند وێنەیەکی بەخۆڕایی مانگانە، پاشان پارەیە |

> API ی فەرمیی گۆگڵ (Custom Search) بۆ بەکارهێنەری نوێ داخراوە و لە ١ی ١ی ٢٠٢٧ دا دەوەستێت، بۆیە Serper بەکارهاتووە.

## فایلەکان
- `Network.kt` — گەڕان، داگرتن، پاشەکەوت
- `BackgroundRemover.kt` — لابردن و وردکردنەوەی لێوار
- `MainViewModel.kt` — لۆجیکی ئەپ
- `MainActivity.kt` — ڕووکار (کوردی، ڕاست بۆ چەپ)
